# Хуки автоматизации (паттерн из ECC)

Хуки — это команды, которые Claude Code запускает автоматически в определённые
моменты (аналогия: как «триггеры» в базе данных или webhooks в Shopify).
В ECC это ядро системы. Здесь — готовый к включению шаблон под Симбу.

> ⚠️ Статус: **не включено**. Это шаблон. Хуки срабатывают на КАЖДОЙ сессии,
> поэтому включать осознанно. Чтобы активировать — перенести блок в
> `.claude/settings.json` (или попросить Claude через скилл `update-config`).

## Какие бывают моменты (события)

| Событие | Когда срабатывает | Зачем в Симбе |
|---------|-------------------|---------------|
| `SessionStart` | В начале сессии | Подгрузить контекст, показать текущую ветку |
| `PreToolUse` | Перед вызовом инструмента | Заблокировать опасные команды (напр. `git push --force`) |
| `PostToolUse` | После правки файла | Отметить файл как изменённый (для форматирования в конце) |
| `Stop` | Когда Claude закончил ответ | Прогнать prettier + `tsc` по всем изменённым файлам разом |

## Ключевая идея ECC (почему это удобно)

Не форматировать/проверять типы после каждой мелкой правки (медленно), а
**накапливать** изменённые файлы через `PostToolUse` и один раз прогнать
форматирование + typecheck в `Stop`-хуке. Быстрее и чище.

## Готовый шаблон для `.claude/settings.json`

```jsonc
{
  "hooks": {
    "Stop": [
      {
        // Прогнать typecheck по серверу после завершения ответа
        "matcher": "",
        "hooks": [
          { "type": "command", "command": "cd server && npx tsc --noEmit || true" }
        ]
      }
    ],
    "PreToolUse": [
      {
        // Предупредить о force-push
        "matcher": "Bash",
        "hooks": [
          { "type": "command", "command": "echo 'Проверь: не force-push ли в защищённую ветку'" }
        ]
      }
    ]
  }
}
```

## Что стоит включить в первую очередь (рекомендация)

1. **Stop → typecheck сервера** — ловит ошибки типов до коммита. Низкий риск.
2. **SessionStart → показать ветку** — напоминание что работаем в `claude/greeting-nnz368`.

Форматирование в Stop-хуке (prettier по всему монорепо) добавлять только после
того, как в проекте настроен единый prettier-конфиг — иначе хук будет менять
чужой стиль. Сначала обсудить с Гермесом.
