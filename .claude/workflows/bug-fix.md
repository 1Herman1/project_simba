# Воркфлоу: Исправление бага

Процесс диагностики и починки. Главное правило: сначала понять ПРИЧИНУ,
потом чинить. Не лечить симптом.

## Шаги

### 1. Зафиксировать симптом
- Что именно сломано (ожидание vs реальность)
- Где проявляется (страница, роут, действие пользователя)
- Воспроизводимо ли? Шаги воспроизведения
- Текст ошибки из консоли браузера / `pm2 logs simba`

### 2. Найти причину → `debugger`
- Передать агенту: симптом + текст ошибки + где проявляется
- Агент трассирует путь исполнения до источника
- НЕ угадывать — найти конкретную строку `файл:строка`
- Отличить причину от симптома (ошибка в UI может идти от сервера)

### 3. Оценить масштаб
- Затрагивает ли баг данные (заказы, бонусы, оплата)? → приоритет выше
- Есть ли похожие места с той же ошибкой? (`researcher` — поиск паттерна)
- Нужна ли миграция БД для фикса?

### 4. Починить → `coder`
- Минимальное изменение, устраняющее причину
- Не рефакторить попутно — только фикс
- Если баг от отсутствия валидации/обработки — добавить на границе

### 5. Проверить
- Воспроизвести исходный сценарий — баг ушёл
- Проверить что фикс не сломал соседнюю логику
- Для багов с данными — проверить на реальном сценарии, не только типы

### 6. Ревью и коммит
- Если фикс в критичном месте (auth, оплата, бонусы) → `code-reviewer`
- `silent-failure-hunter` если трогали обработку ошибок
- Коммит: `fix: <что чинили>`, пуш на `claude/greeting-nnz368`

## Частые источники багов в Симбе
| Симптом | Где искать |
|---------|-----------|
| Цена отображается в 100× | Копейки не поделены на 100 при выводе |
| «Чужой» заказ виден пользователю | Нет фильтра по `userId` в Prisma-запросе (IDOR) |
| OTP не приходит | SMS = только `console.log`, провайдер не подключён |
| Бонусы начислены неверно | Логика 5% / уровней в сервисе заказов |
| Изображение товара не грузится | Политика bucket MinIO / URL |

## Чеклист
- [ ] Симптом воспроизведён
- [ ] `debugger` нашёл причину (`файл:строка`), а не симптом
- [ ] Проверено нет ли того же бага в других местах
- [ ] Фикс минимальный, без попутного рефакторинга
- [ ] Исходный сценарий больше не воспроизводится
- [ ] Закоммичено и запушено
