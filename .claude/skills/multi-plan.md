## Как использовать

Когда задача большая — не делай всё сам. Раздели на независимые части и запусти агентов параллельно.

## Шаблон запуска

1. **Разбей задачу** на независимые части (исследование, реализация, проверка)
2. **Запусти агентов параллельно** — все независимые задачи в одном вызове Agent tool
3. **Дождись всех** — не начинай следующий шаг пока не завершились все агенты
4. **Собери результат** — синтезируй ответы агентов и передай пользователю

## Пример разбивки задачи "добавить фичу X"

Параллельно:
- `Explore` → найти все файлы которые затронет фича
- `architect` → спроектировать как это должно работать

После получения результатов:
- `coder` → реализовать (с контекстом от Explore + architect)

После реализации параллельно:
- `code-reviewer` → проверить качество
- `Explore` → найти что могло сломаться

## Правила

- Независимые задачи — ВСЕГДА параллельно
- Зависимые задачи — строго последовательно
- Передавай агенту полный контекст: пути файлов, что уже известно, что нужно сделать
- Не дублируй работу агента — если он читает файл, не читай его сам
