# 3D-декор для секции «Подбор корма»

Положите сюда два изображения — они встанут слева и справа от карточки
«Не знаете, какой корм выбрать?» на главной.

| Файл             | Место                        |
|------------------|------------------------------|
| `quiz-left.png`  | слева от карточки            |
| `quiz-right.png` | справа от карточки           |

Требования:
- **PNG с прозрачным фоном** (или WEBP) — объект без белого прямоугольника вокруг;
- вертикальная ориентация, примерно 600×800 px и больше;
- 3D-рендер или объёмное фото: банка корма, миска, игрушка, питомец.

Пока файла нет — на его месте ничего не показывается (без «битой» картинки).
Изображения декоративные: они скрыты от скринридеров и не мешают клику по кнопке.

Животные стоят поверх карточки: лапа и нос ложатся на баннер, остальной силуэт
уходит за его край. Анимации нет.

ВАЖНО про текущие файлы: в них запечена непрозрачная белая кромка («стена»,
из-за которой выглядывает животное). Сейчас она невидима только потому, что
совпадает с белым фоном карточки. Поэтому фон карточки должен оставаться белым.
Более устойчивый вариант — прислать два слоя: силуэт целиком и отдельно
лапу/нос (тогда фон карточки можно менять свободно).

Ниже 1024px декор не выводится вовсе — на узком экране места по бокам нет,
и файлы там даже не скачиваются.
