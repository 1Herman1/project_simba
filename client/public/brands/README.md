# Логотипы брендов для секции «Бренды, которым мы доверяем»

Положите сюда PNG с прозрачным фоном (или SVG) — логотип встанет в карточку
бренда на главной вместо текстового названия.

**Имя файла обязано совпадать со слагом бренда из базы** (`/brands/<slug>.png`).
Иначе картинка отдаст 404 и плитка молча покажет название текстом — так уже было
с `hills.png` при слаге `hill-s`.

## Бренды в базе и наличие логотипа

| Слаг          | Бренд        | Логотип |
|---------------|--------------|---------|
| `farmina`     | Farmina      | ✅ есть |
| `monge`       | Monge        | ✅ есть |
| `hill-s`      | Hill's       | ✅ есть |
| `royal-canin` | Royal Canin  | ✅ есть |
| `grandorf`    | Grandorf     | ❌ нет  |
| `zillii`      | Zillii       | ❌ нет  |
| `alleva`      | Alleva       | ❌ нет  |
| `craftia`     | Craftia      | ❌ нет  |
| `muzzle`      | Muzzle       | ❌ нет  |
| `alphapet`    | AlphaPet     | ❌ нет  |
| `happy-cat`   | Happy Cat    | ❌ нет  |
| `happy-dog`   | Happy Dog    | ❌ нет  |

Бренды без логотипа показываются оформленной текстовой плиткой — это штатное
состояние, а не поломка. Чтобы заменить на логотип, положите файл с точным именем
слага из таблицы.

Требования:
- PNG с прозрачным фоном или SVG — без белой подложки вокруг;
- логотип по горизонтали, высота ориентировочно 40–60px при пропорциональной ширине;
- если только PNG — можно и растровый, но чем чище вырезан фон, тем аккуратнее карточка.
