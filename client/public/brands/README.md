# Логотипы брендов для секции «Бренды, которым мы доверяем»

Положите сюда PNG с прозрачным фоном (или SVG) — логотип встанет в карточку
бренда на главной вместо текстового названия.

| Файл                 | Бренд           |
|----------------------|------------------|
| `hills.png`           | Hill's           |
| `farmina.png`         | Farmina          |
| `monge.png`           | Monge            |
| `royal-canin.png`     | Royal Canin      |
| `purina.png`          | Purina Pro Plan  |
| `brit.png`            | Brit             |
| `acana.png`           | Acana            |
| `orijen.png`          | Orijen           |

Требования:
- PNG с прозрачным фоном или SVG — без белой подложки вокруг;
- логотип по горизонтали, высота ориентировочно 40–60px при пропорциональной ширине;
- если только PNG — можно и растровый, но чем чище вырезан фон, тем аккуратнее карточка.

Пока файла нет — в карточке остаётся текстовое название бренда (как сейчас),
без «битой» картинки.
