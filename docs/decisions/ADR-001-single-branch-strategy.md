# ADR-001: Единая рабочая ветка

**Дата:** 2026-07-08  
**Статус:** Принято

**Контекст:**  
В репозитории накопилось 3 ветки (claude/great-volta-gdlya3, claude/github-token-remote-url-m5d18m, claude/greeting-nnz368) с дублирующейся конфигурацией агентов и кодом приложения. Между сессиями агенты терялись так как хранились в ~/.claude/agents/ (не в git).

**Решение:**  
Вся работа ведётся в одной ветке `claude/greeting-nnz368`. Агенты, скиллы и воркфлоу хранятся в `.claude/` внутри репозитория — так они не теряются между сессиями. Старые ветки удалены.

**Альтернативы:**  
- Глобальные агенты в ~/.claude/agents/ — теряются при пересоздании контейнера  
- Отдельная ветка для конфигурации — усложняет синхронизацию  

**Последствия:**  
При каждой новой сессии Claude читает CLAUDE.md и .claude/ из репозитория — контекст всегда актуален.
