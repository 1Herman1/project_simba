# ADR-001: Единая рабочая ветка

**Дата:** 2026-07-08  
**Статус:** Принято

**Контекст:**  
В репозитории накопилось несколько веток с дублирующейся конфигурацией агентов и кодом приложения. Между сессиями агенты терялись так как хранились в ~/.claude/agents/ (не в git).

**Решение:**  
Вся работа ведётся в одной ветке `claude/greeting-nnz368`. Агенты, скиллы и воркфлоу хранятся в `.claude/` внутри репозитория — так они не теряются между сессиями. Остальные ветки (включая `claude/greeting-v1rxbb`) считаются побочными и не используются для основной разработки; новые изменения в них не вносятся.

**Альтернативы:**  
- Глобальные агенты в ~/.claude/agents/ — теряются при пересоздании контейнера  
- Отдельная ветка для конфигурации — усложняет синхронизацию  

**Последствия:**  
При каждой новой сессии Claude читает CLAUDE.md и .claude/ из репозитория — контекст всегда актуален.
