# Architecture Decision Records (ADR)

Здесь фиксируются важные архитектурные решения проекта Симба.

## Зачем

Когда через 3 месяца спросишь "почему мы сделали X а не Y" — ответ будет здесь.

## Формат

Каждое решение — отдельный файл: `ADR-001-название.md`

## Шаблон

**Название:** Короткое описание решения  
**Дата:** YYYY-MM-DD  
**Статус:** Принято / Отклонено / Устарело

**Контекст:** Почему вообще встал этот вопрос  
**Решение:** Что выбрали  
**Альтернативы:** Что рассматривали  
**Последствия:** Что это значит для проекта
