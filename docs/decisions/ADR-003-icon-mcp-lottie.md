# ADR-003: MCP-сервер иконок (Iconify + LottieFiles), включая Lottie-анимации

**Дата:** 2026-08-21
**Статус:** Принято

**Контекст:**
Нужен самостоятельный доступ к каталогу иконок (статичных и анимированных)
для агентов отдела дизайна. Изначально запрошен Flaticon — при проверке их
условия использования оказались прямо запрещающими автоматический/бот-доступ
(«строго запрещено», вплоть до блокировки аккаунта); платный официальный API
не снимает сути задачи «сам заходит и берёт». Скрейпинг сайтов, чьи ToS это
запрещают, не делаем ни при каких обстоятельствах.

До этого решения в проекте не было ни одной анимированной (Lottie) иконки —
только CSS-transitions (`docs/core/motion.md`). Подключение Lottie — реальный
разворот: новая фронтенд-зависимость, новый паттерн ассетов.

**Решение:**
- Статичные SVG — через **Iconify** (`api.iconify.design`), публичный API без
  ключа, 300k+ иконок из 200+ открытых наборов (Lucide, Heroicons, Feather,
  Tabler и др.), лицензии MIT/Apache. Совпадает по стилю с уже используемым в
  проекте набором (`client/src/components/icons.tsx`).
- Анимации — через **LottieFiles**, официальный Developer Portal, бесплатные
  публичные анимации под Lottie Simple License (коммерческое использование
  без атрибуции).
- Реализовано как собственный MCP-сервер (`tools/icon-mcp-server/`),
  зарегистрированный в `.mcp.json`, и новый агент `icon-curator` в отделе
  дизайна (`.claude/agents/design-department.md`).
- Плеер для воспроизведения Lottie на фронте — `@lottiefiles/dotlottie-web`
  (легче классического `lottie-web`), ставится в тот workspace, где реально
  понадобится первым — не заранее в оба.
- Дисциплина использования Lottie — `docs/core/motion.md`, раздел
  «Lottie-анимации (иконки)»: только когда статичный SVG недостаточен,
  lazy-load, бюджет размера, `prefers-reduced-motion`.

**Альтернативы:**
- Flaticon (платный API) — отклонено: не решает суть задачи, дороже, ToS их
  сайта категорически против автоматизации на уровне обычного доступа.
- Не подключать Lottie вообще, остаться на чистом CSS — рассмотрено, но
  пользователь явно запросил анимированные иконки; статичный SVG не всегда
  достаточен (loading/success-состояния).

**Ограничение на момент принятия:**
Интеграция с LottieFiles (`tools/icon-mcp-server/src/clients/lottiefiles.ts`)
писалась в сетевой песочнице, которой организационная политика блокирует
исходящие соединения на `developers.lottiefiles.com` (403 policy denial на
уровне egress-прокси) — точный формат эндпоинтов/авторизации не был проверен
на живом API. Часть с Iconify проверена и работает. Первый реальный вызов
Lottie-инструментов может потребовать поправить `BASE_URL`/заголовки в
`clients/lottiefiles.ts` по актуальной документации
developers.lottiefiles.com — это единственное место, которое это касается.

**Последствия:**
Появилась новая фронтенд-зависимость (`@lottiefiles/dotlottie-web`) и новый
класс ассетов (`*/src/assets/lottie/`). Каждая сохранённая иконка/анимация
обязана нести пометку источника и лицензии (правило агента `icon-curator`).
