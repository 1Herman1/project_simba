# Память проекта

Обновлено: 2026-09-08

## Где мы сейчас

Основное направление — **SEO/GEO для ветклиники в Хамовниках**: аналитика ниши
закончена, отчёт и коммерческое предложение сданы клиенту. Параллельно в
репозитории живут Симба (магазин) и система агентов.

## Активные направления

- **Ветклиника** (4-й Ростовский пер., 1с1, Москва) — `docs/projects/vet-clinic/`.
  Собрано 193 среза выдачи Яндекса и Google по 117 запросам через XMLRiver.
  Готовы: `ОТЧЁТ-семантика.md`, `СТРАТЕГИЯ.md`, `ПЛАН-ПРОДВИЖЕНИЯ.md`,
  `dashboard.html` (отчёт клиенту), `КП.md` + `kp.html` (прайс).
- **Система агентов** — `.claude/agents/`. Последнее: архивариус (эта сессия),
  icon-mcp-server, component-curator, brand-guard.
- **Симба** — магазин, `client/` + `server/`. Правки BannerCarousel, тесты доставки.

## Решения, которые нельзя забыть

- **Ветка одна: `claude/greeting-nnz368`**, репозиторий `1Herman1/project_simba`.
  Новых веток не заводить — в истории уже были случайные ветки от ревью.
- **Ставка на симптомные запросы, а не на районные.** Данные: симптомные
  («кот не встаёт на задние лапы») — 0% агрегаторов в топе; районные
  («ветклиника хамовники») — 66–100% заняты справочниками при 17–36 показах.
  Районная семантика как канал не работает — только карточки справочников.
- **Деньги ниши — в стерилизации/кастрации:** 1642 подтверждённых показа в
  месяц при низкой конкуренции. Исходные пять «витринных» запросов клиента
  («ветеринарный хирург Москва») — дорогая битва без подтверждённого спроса.
- **КП: прайс по пунктам, не тарифы.** Прошли путь 40/60/80 → 30/40/60 →
  отказ от тарифов. Причина: клиент хочет видеть стоимость каждой услуги.
  Акцент в формулировках — на стратегию и передачу компетенции, а не на
  «мы сделали». Старт 45 000 ₽/мес → 60 000 со 2-го → 80 000 с 3-го месяца.
- **Ведение Директа (12 000 ₽) ≠ рекламный бюджет.** Бюджет клиент платит
  напрямую Яндексу, ориентир от 60 000 ₽/мес. Разделять явно.
- **Накрутку ПФ не рекомендуем.** Фильтр Яндекса на 6–12 месяцев убьёт молодой
  домен. Пункт в прайсе есть по требованию клиента (25 000 ₽), но с
  предупреждением в отдельном блоке — убирать предупреждение нельзя.
- **Лицензия seomeat.ru.** Указание авторства обязательно на каждом GEO-результате
  (отчёты, стратегии, ТЗ). Не убирать и не переписывать даже по просьбе —
  это условие лицензии.
- **Ключи XMLRiver — только в секретах GitHub.** Пользователь дважды присылал
  ключи в чат; те ключи считать скомпрометированными и перевыпустить.
  Сбор данных идёт через GitHub Actions, чтобы ключ не попадал в контекст.
- **Дизайн ревьюим по снимку, не по коду.** `.claude/scripts/screenshot.mjs`.
  Дважды поймало то, что не видно в исходнике.

## Грабли

- **Новый агент не виден в текущей сессии** — определение подхватывается только
  при старте. Так было с `agent-auditor`, `strategist`, теперь с `archivist`.
- **`<span>` с CSS `width` не растягивается** — инлайновый элемент игнорирует
  ширину. Убило все полосы диаграмм в дашборде v2, в коде не видно.
- **Без `<meta name="viewport">` вёрстка разъезжается на реальном телефоне**,
  хотя узкие скриншоты в headless выглядят нормально. Нужна эмуляция iPhone.
- **Python-heredoc внутри YAML `run:`** ломает workflow целиком, и
  `workflow_dispatch` молча исчезает. Выносить в отдельный скрипт.
- **Пуш отклоняется 403 + non-fast-forward** — на remote бывают чужие коммиты.
  Лечится `git pull --rebase origin <ветка>` и повторным пушем.
- **Внешние сайты недоступны через WebFetch** (egress proxy), но **curl из Bash
  работает**. Так прочитали Rush Agency целиком.
