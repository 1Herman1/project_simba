# Лог сессий

Резюме каждой сессии работы над Симбой — что сделано, что отложено, что
запомнить. Создаётся командой `/summary` в конце сессии.

Файлы по датам: `YYYY-MM-DD-слаг.md`, самые свежие внизу списка по имени файла.

## Зачем

Между сессиями теряется контекст (новый чат = чистая память). Вместо того
чтобы пересказывать всё вручную — Claude в начале сессии читает файл с самой
свежей датой из этой папки.

## Как пользоваться

- В конце сессии (или когда чувствуешь что пора закругляться) — скажи `/summary`
- В начале новой сессии Claude сам находит и читает последний файл отсюда
