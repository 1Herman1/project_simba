# Anti-patterns: безопасность (Симба)

Негативный список того, что модель по привычке пишет «небезопасно средне».
Читается security-ревьюерами (`security-auth-access`, `security-secrets-scanner`,
`security-infra-cloud`); сверять находки с этим файлом.

Стек: Fastify + свой OTP (email/SMS) + JWT + Prisma + MinIO на Timeweb VPS.

## Секреты
- ❌ API-ключ / пароль / `JWT_SECRET` / URL с credentials строкой в коде или `.md`
- ❌ Секрет в `.env.example` со значением (там только пустые ключи)
- ❌ Коммит `.env` (должен быть в `.gitignore`)
- ❌ Секрет в логах (`console.log(token)`, лог тела запроса с паролем/OTP)

## Аутентификация / авторизация
- ❌ Роут с данными пользователя без `preHandler: [authenticate]`
- ❌ Доступ к ресурсу без проверки владельца — IDOR: взять `id` из params и не
  сверить с `req.user.userId` (пользователь читает/меняет чужое)
- ❌ Роль/права из тела запроса (`req.body.role`) вместо токена (`req.user.role`)
- ❌ JWT без срока (`expiresIn`) или с секретом-заглушкой
- ❌ OTP без rate limit (в Симбе — 5 попыток / 15 минут) или сравнение кода без
  защиты от перебора
- ❌ Ответ, раскрывающий существование пользователя («email не найден» vs общий текст)

## Ввод / вывод
- ❌ `dangerouslySetInnerHTML` с непроверенными данными (XSS)
- ❌ `prisma.$queryRawUnsafe` / конкатенация SQL из пользовательского ввода
- ❌ Внешние данные (fetch, API-ответ, загруженный файл) считать доверенными
- ❌ Путь к файлу из пользовательского ввода без нормализации (path traversal)

## Инфраструктура
- ❌ `cors: { origin: '*' }` в проде — только явный список доменов
- ❌ Публичный bucket MinIO / раздача приватных изображений без подписи
- ❌ Отсутствие лимита размера тела запроса / загружаемого файла
- ❌ Стек-трейс/детали ошибки в ответе клиенту в проде
