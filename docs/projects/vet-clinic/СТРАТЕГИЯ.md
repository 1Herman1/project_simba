# Стратегия выхода: ветклиника премиум-сегмента, Хамовники

**Дата:** 2 сентября 2026. Основано на данных живой выдачи (193 среза, Яндекс +
Google, Москва) и Wordstat. Детальные цифры — в `ОТЧЁТ-семантика.md`.

---

## Вывод по нише одним абзацем

Ниша ветеринарии в Москве разделена на два мира. Мир «найти клинику» (рядом со
мной, район, ЦАО) принадлежит справочникам — Яндекс.Картам, Zoon, 2ГИС: они
держат до 83–100% верха выдачи, и сайту туда входа нет. Мир «решить проблему
питомца» (стерилизация, симптомы, породные болезни, уход после операции)
справочникам неинтересен — там конкурируют обычные клиники, ни одна не
доминирует, и место для нового сильного сайта есть. Стратегия из этого следует
прямо: в первом мире присутствовать через карточки справочников, во втором —
строить сайт и забирать спрос контентом.

## Мои мысли — что здесь самое важное

1. **Данные опровергли интуицию, и это ценно.** Исходная ставка «район = низкая
   конкуренция» казалась очевидной — и оказалась ошибкой по обоим измерениям:
   спроса нет (17–36 показов), а конкуренция максимальная (66% справочников).
   Решения по продвижению в этой нише нельзя принимать без цифр.
2. **Воронка начинается раньше, чем кажется.** Клиент хирургии не ищет
   «остеосинтез» — он ищет «собака хромает на заднюю лапу». Кто отвечает на
   симптомный вопрос, тот и получает пациента. Симптомный контент — это не
   «блог для SEO», это приёмное отделение сайта.
3. **Стерилизация — троянский конь премиума.** Массовая, понятная, сравнимая по
   цене услуга с реальным спросом (1642 показа). Клиент приходит на неё,
   убеждается в уровне — и возвращается со сложным случаем, где премиум и
   зарабатывает. Гордость хирурга — сложные операции; деньги маркетинга — в
   простых.
4. **GEO здесь не мода, а совпадение форматов.** Нейросети цитируют страницы,
   которые отвечают на вопросы. Симптомные и уходовые материалы — ровно такой
   формат. Делая контент для людей в тревоге, клиника автоматически делает
   контент для ИИ-ответов. Двух отдельных работ нет — есть одна.
5. **Отзывы — валюта премиума.** Для чека в десятки тысяч рублей рейтинг 4.9
   против 4.5 весит больше, чем позиция 3 против 7. Репутационное поле мы пока
   не измеряли — это следующий срез.

## Стадии развития от старта

### Стадия 0 — до открытия (сейчас)

- Карточки в Яндекс.Бизнес, 2ГИС, Zoon: услуги с ценами, фото врачей и
  операционной, кликабельный телефон. Единственный канал, работающий без сайта.
- Решить два вопроса, блокирующих половину стратегии: **название** (без него
  мониторинг бренда измеряет ноль) и **режим работы** (половина
  премиум-семантики опирается на круглосуточность).
- Услуга «второе мнение» — консультация по чужим снимкам. Запускается до
  открытия, приводит самого тёплого клиента: того, кто уже лечится в другом
  месте и недоволен.

### Стадия 1 — запуск, месяцы 0–3

- Сайт на двух опорах: страницы стерилизации/кастрации (кошки и собаки
  отдельно: цена, подготовка, наркоз, восстановление) + 10–15 симптомных
  материалов по собранному списку.
- Тон симптомных страниц — отдельный: короткий ответ «что делать сейчас» и
  телефон; имиджевый глянец здесь вреден.
- Отзывы с первого рабочего дня — просить каждого довольного клиента.
- Директ на экстренные и стерилизационные запросы с посадкой на эти страницы —
  органика ещё не работает, платный трафик проверяет конверсию страниц.
- Коллтрекинг с первого дня: без него через полгода нельзя сказать, что
  сработало.

### Стадия 2 — рост, месяцы 3–6

- Породные кластеры: вывих чашечки у таксы, брахицефальный синдром, МКБ у
  мейн-кунов. Конкуренция 1%, намерение точное, профиль наш.
- Возрастной кластер: «выдержит ли наркоз в 15 лет» — главное возражение
  аудитории, у которой питомец — член семьи.
- Послеоперационный уход — материалы, которые удерживают клиента и цитируются
  нейросетями.
- Аудит доступности сайта для ИИ-ботов (llm-accessibility): пускает ли
  robots.txt, извлекается ли текст, видны ли цены. До сайта этот аудит был
  невозможен — теперь обязателен.
- Врачи как поисковый актив: страницы хирургов с регалиями; если врач с
  именем — семантика по фамилии.

### Стадия 3 — система, месяцы 6–12

- Ежемесячный мониторинг: позиция в выдаче, присутствие в ИИ-ответе,
  цитирование URL, упоминание бренда — четыре раздельные метрики.
- Внешние размещения: площадки, которые нейросети уже цитируют в этой нише
  (список собирается методикой find-placements по накопленным данным).
- Экзотика как дифференциатор — если подтверждается решением клиники.
- Пересбор выдачи и частотности: ниша живая, срез устаревает за квартал.

## Что нужно уметь, чтобы конкурировать

### В классическом SEO

| Возможность | Зачем |
|---|---|
| Карточки справочников на максимум | Верх выдачи по «найти клинику» — это они |
| Страницы услуг с открытыми ценами | «Дорого и понятно за что» — премиум доказывается прозрачностью |
| Симптомный контент | Вход в воронку до слова «операция» |
| Скорость и мобильность | Тревожный клиент — с телефона; медленная страница = потерянный звонок |
| Микроразметка VeterinaryCare/LocalBusiness | Поисковик должен понимать: клиника, адрес, часы, врачи |
| Массив отзывов и работа с ними | Решающий фактор выбора в премиуме |
| Коллтрекинг | В медицине конвертирует звонок, а не форма |

### В GEO (видимость в ИИ-ответах)

| Возможность | Зачем |
|---|---|
| Страницы-ответы: вопрос → короткий ответ → детали | Нейросети цитируют этот формат, а не карточки услуг |
| Техническая доступность для ИИ-ботов | Закрытый robots или нерендерящийся текст = невидимость |
| Факты с числами: цены, сроки, дозировки наблюдения | ИИ охотнее цитирует конкретику, чем маркетинг |
| Автор-врач у материала | Медицина — зона повышенных требований к доверию |
| Упоминания на цитируемых площадках | ИИ собирает ответ из нескольких источников |
| Мониторинг цитируемости | Без замера нельзя понять, работает ли всё выше |

## Ограничения этого анализа

Частотность подтверждена по 20 запросам из 117 (по остальным Wordstat вернул
пустые списки — вероятно, спрос ниже порога, но это не доказано). Блок карт в
выдаче не парсился — доля справочников по гео-запросам занижена. Бюджеты
Директа не измерялись. Репутационное поле конкурентов не измерялось.
