## Примечание к поведенческим факторам

Пункт подключается только по отдельному согласованию: Яндекс распознаёт
искусственные переходы, санкция — фильтр на 6–12 месяцев. Для молодого
домена риск максимальный, поэтому на первый год безопаснее получать те же
сигналы через Директ и справочники (реальные переходы реальных клиентов).
Если пункт подключается — работа ведётся малыми объёмами и с ежемесячным
контролем позиций.
