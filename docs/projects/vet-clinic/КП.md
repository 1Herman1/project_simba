## Примечание к поведенческим факторам

Подключается отдельным решением: Яндекс распознаёт искусственные переходы,
санкция — фильтр на 6–12 месяцев, для молодого домена риск максимальный.
При подключении работа ведётся малыми объёмами с ежемесячным контролем.

## Порядок работы

1. Согласовываем состав пунктов, фиксируем в договоре.
2. Снимаем «Прогноз бюджета» Директа — стоимость клика известна до старта.
3. Первые работы — справочники — в течение 3 дней.
4. Отчёт ежемесячно: что сделано по каждому направлению, позиции, звонки,
   что клиника узнала и может делать сама. Состав на следующий месяц
   корректируется по результатам.
