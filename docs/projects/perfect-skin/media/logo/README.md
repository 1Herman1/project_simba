# Логотип Perfect Skin

Сюда кладём **исходники знака от заказчика**. Сейчас логотип на макетах
набран шрифтом Playfair Display — это близкая, но не настоящая отрисовка:
переплетение P и S с росчерком шрифтом не повторяется.

## Что положить

| Файл | Что это | Приоритет |
|---|---|---|
| `logo-full.svg` | Полный лок-ап: монограмма + черта + надпись | главный |
| `monogram.svg` | Только монограмма PS | главный |
| `favicon.svg` | Знак для фавикона (синяя плитка с золотой PS) | желательно |
| `logo-full.pdf` / `.ai` | Исходник для печати | если есть |

**Лучший формат — SVG** (векторный): масштабируется без потери качества и
перекрашивается под палитру одной строкой. Подойдут также AI и PDF.

Если вектора нет — **PNG без фона** (прозрачность), шириной от 2000 px.
JPG не подходит: у него не бывает прозрачного фона.

## Что произойдёт после

Знак и фавикон в макетах заменяются на настоящие. Разметка под это уже
готова — правка занимает минуты, переверстки не требует.

## Утверждённые цвета знака

| Где | Значение | Почему |
|---|---|---|
| Крупная подача | `#D6A75E` | золото с присланного лок-апа |
| Шапка сайта | `#A87C2F` | тот же тон глубже: в шапке штрихи волосяные, и золото лок-апа даёт нечитаемые 1.9:1 |
| Фавикон | `#E4D3AC` на `#1F3A5F` | как на фирменном борде, контраст 7.77:1 |

Источник значений — `tools/brand.json` в превью-репозитории.
