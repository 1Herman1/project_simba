# Медиа Perfect Skin

Сюда кладём кадры, фото и видео для концептов и будущего сайта.

## Куда что класть

- `bestsellers/` — кадры и видео для новой секции «Бестселлеры».
  Складывай сюда всё из своей папки с фреймами.

## Форматы

- Видео: `.mp4` (лучше всего) или `.webm`.
- Кадры/фото: `.jpg`, `.png` или `.webp`.
- Имя файла — латиницей, без пробелов (пример: `frame-01.jpg`, `promo.mp4`).

После загрузки — сообщи Клоду, он подтянет файлы и соберёт секцию.

## Раскадровка bestsellers (загружено заказчиком)

- `1.png` — все 4 товара в ряд, без руки (нейтральный кадр).
- `3.png` — рука держит **DERMOSUN SPF 50** (товар 1).
- `5.png` — рука на **O3 DEPUR** (товар 2).
- `7.png` — рука на **TONICO FACIAL EQUILIBRANTE** (товар 3).
- `9.png` — рука тянется к **FLUIDO VISCOSO FORTE** (товар 4).
- `2/4/6/8.png` — промежуточные (нейтральные) кадры.
- `*-*.mp4` — видео движения руки между состояниями (1-2, 2-3, 3-5, 5-7, 7-9, 9-1).

В КОНЦЕПТ-HTML использованы кадры 3/5/7/9 (кроссфейд) — они лёгкие и едут внутри
файла. Видео тяжёлое (~8 МБ суммарно), в скачиваемый HTML не вшивается; оно
пойдёт в дело на боевом React-сайте как scroll-scrubbed видео (проигрывание,
привязанное к скроллу, в стиле Apple).
