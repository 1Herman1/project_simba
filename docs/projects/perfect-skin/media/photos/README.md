# Фотографии Perfect Skin

Съёмка от клиента. Раскладка по трём папкам — по пригодности для сайта,
а не по красоте: красивы почти все.

## `clean/` — без впечатанного текста, идут в дело как есть

Основа сайта. Сюда: руки с банками (ч/б), три банки ISSÉIMI в воде,
ISSÉIMI Élite с каплями, FGF два флакона, GLACÉE Redensificante с коробкой,
GLACÉE Contour-K на чёрном с зёрнами, рука с Vitamina C, GLACÉE на ротанге.

## `text/` — с надписями, годятся после кадрирования

Посты для соцсетей: поверх фото уже лежит английский текст, а мы кладём свою
типографику. Берём чистые куски кадра. Сюда: косметолог с кистью (ч/б),
Charcoal Mask с углём, EGF с веерной кистью (единственный горизонтальный),
двойное очищение, HYDROCOMBAT, отзыв Laura T.

## `offpalette/` — не подходят по цвету

Апельсиновый, бирюзовый, розовый, персиковый, тёмно-зелёный фоны спорят с
утверждённой палитрой «Старое золото и морская синь». Не мусор — годятся для
блога и сезонных акций, но не для каркаса сайта.

## Требования к размеру

| Место | Нужен файл |
|---|---|
| Карточка товара в каталоге | от 600 px |
| Карточка бренда | от 800 px |
| Первый экран | от 1200 px |
| Панель категории | от 1600 px, горизонтальная |

Выгрузка из соцсетей — это 1080 px по ширине, а квадраты 800. На карточки
хватает, на первый экран и панели категорий — впритык или мало, особенно
после кадрирования. Если у клиента есть исходники до соцсетей — они лучше.

## Чего не присылать

Скриншоты, пересланное мессенджером (сжимается), коллажи из нескольких
товаров в одном кадре, фото с водяными знаками.
